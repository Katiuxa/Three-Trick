# Three-Trick

The physical tile puzzle, brought to the screen. Slide a tile, lift it, and drop it until the pieces sit in order from 1 to 9. Web and Android.

## Web

https://tritrick.vercel.app

Source is in `src/`.

```bash
npm ci
npm run dev
```

## Android

Capacitor, in `android/`. Version **1.0.24**.

```bash
npm ci
npm run apk
```

The Play Store keystore stays outside git.
